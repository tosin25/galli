Manuscript in, book out.

1How do you want to set the style?

Both modes end the same way: Galley builds real InDesign pages with paragraph styles, anchored objects and QA.

Style from sample pages InDesign panel, next Lay out a few sample pages yourself in InDesign, open the Galley panel, drop in the manuscript, and Galley fills the rest in your styles. In this prototype: build your sample, then run galley.ps1 check for QA. The UXP panel is on the roadmap.
Style from references working prototype Upload the manuscript and 15–20 reference pages. Galley turns them into style parameters, builds one chapter in several looks, you pick one, Galley builds the rest.

2Reference checklist

Required items are marked. References tell Galley what kind of treatment you want; they are never copied onto the page.

3Read the manuscript

Galley tags headings, body, examples, exercises, questions, tables, figures and notes. Check the decisions before building.

4Build one chapter in several looks

Each look is a full InDesign build with a PDF, page previews and an automatic QA pass (overset text, split boxes, stranded headings, objects off the page, missing links).
